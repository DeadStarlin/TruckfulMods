# Truckful Cargo Stickiness

BepInEx 6 IL2CPP plugin, built against the assemblies installed alongside this game.

Installed DLL: `BepInEx/plugins/TruckfulCargoStickiness.dll`.
Configuration: `BepInEx/config/local.truckful.cargostickiness.cfg`.
Close the game before editing configuration, then restart.

- `FrictionMultiplier = 3`: multiply cargo collider static and dynamic friction. `1` preserves original materials; `0` removes cargo-side friction; allowed range `0–10`. Above `1`, use Maximum friction combining to improve contact grip. This affects package collisions, including packages outside the bed. It does not anchor items against bouncing or tipping, and higher values are not a linear retention-strength guarantee.
- `AlwaysGlue = false`: change to `true` to keep the existing hidden StickyCargoSkill active while that component is enabled. Uses the game's own joints and cargo-rebuild handling, with no duration or charge consumed by the mod. Normal active abilities remain under game control. This is an on/off glue mode, not adjustable glue-joint strength. It depends on the game enabling its StickyCargoSkill component.

The inspected game exposes glue methods and physics material settings, but no existing user-facing cargo friction configuration was found. The mod changes runtime objects rather than save files or game assets.

Build from the repository root: `pwsh -NoProfile -File ./CargoStickinessMod/build.ps1`.
Checks from the repository root: `pwsh -NoProfile -File ./CargoStickinessMod/test.ps1` in a fresh PowerShell process. Tests exercise the actual plugin source against lightweight stubs: numeric bounds, friction, trigger exclusion, cleanup, vanilla mode, glue callback deduplication, re-enabling and coexistence with another glue user. The plugin also runs numeric self-checks when loaded.

Compilation against real game assemblies and stub checks passed. In-game handling and native Harmony callbacks have not been verified. Disable by removing only `BepInEx/plugins/TruckfulCargoStickiness.dll` while the game is closed.

## Installation

Requires **BepInEx 6.0.0-be.788+5b766a3, Unity IL2CPP, Windows x64**. Follow the [repository setup instructions](../README.md#requirements-and-installation) to install the loader and generate interop assemblies. Build requirements and an explicit `-GameRoot` example are in the [build guide](../README.md#build).

With the game closed, copy `TruckfulCargoStickiness.dll` from this folder into `<game>/BepInEx/plugins/`, then restart. The DLL is generated by `build.ps1`; it is not tracked in Git. To update, replace the installed DLL with the game closed. To uninstall, remove it.
