# Truckful Truck Parts

BepInEx 6 IL2CPP plugin, built against this installation's interop assemblies.

Installed DLL: `BepInEx/plugins/TruckfulTruckParts.dll`
Configuration: `BepInEx/config/local.truckful.truckparts.cfg`

- `UnlockAllParts = true`: all database truck parts are available in the garage/shop; normal purchase prices remain.
- `AllPartsPurchased = true`: all parts are treated as owned and ready to equip without paying. This also unlocks parts even if UnlockAllParts is false.
- Both false: normal game behavior.
- Under `[Skills]`, `RamAlwaysActive = true` enables the normal ram collision behavior without using an equipment slot.
- `SnorkelAlwaysActive = true` enables the truck's existing snorkel intake colliders and calibrated heights without using an equipment slot. Water above snorkel height can still drown the engine.

Close the game before editing the config, then restart. Defaults: unlock enabled; purchased, ram and snorkel disabled. Updating the plugin preserves existing part settings.

Patches the shared CarPart IsUnlocked, IsAvailableInShop and IsBought getters, reapplies DestructableEnviro.IsUsingRam after SkillsController.OnSkillsChanged, and forces SnorkelSkill activation at setup/start. Passive effects do not add equipment visuals or write skill slots. It does not write ownership lists or grant currency. Normal equipment changes and purchases still use the game's save system. Back up your save before equipping progression parts; after disabling the mod, equipped parts may remain saved while ownership returns to normal.

Includes every category in the game's parts database (engine, steering, suspension, wheels, brakes, body, color, cargo space, skills). Does not create missing assets or bypass skill-slot limits, demo filters, or other game rules.

Build from the repository root: `pwsh -NoProfile -File ./TruckPartsMod/build.ps1`
Config logic checks from the repository root: `pwsh -NoProfile -File ./TruckPartsMod/test.ps1`

Verified compilation against installed BepInEx/game assemblies, all part config combinations, passive effect enabled/disabled and equipped/unequipped combinations, and repeated snorkel initialization with stub tests. Inspected native snorkel activation: it swaps intake collider GameObjects and recalculates their heights. In-game collisions, water traversal and equipping have not been verified.

Remove the installed DLL with the game closed to uninstall.

## Installation

Requires **BepInEx 6.0.0-be.788+5b766a3, Unity IL2CPP, Windows x64**. Follow the [repository setup instructions](../README.md#requirements-and-installation) to install the loader and generate interop assemblies. Build requirements and an explicit `-GameRoot` example are in the [build guide](../README.md#build).

With the game closed, copy `TruckfulTruckParts.dll` from this folder into `<game>/BepInEx/plugins/`, then restart. The DLL is generated by `build.ps1`; it is not tracked in Git. To update, replace the installed DLL with the game closed. To uninstall, remove it.
