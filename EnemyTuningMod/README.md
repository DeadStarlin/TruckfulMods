# Truckful Enemy Tuning

BepInEx 6 IL2CPP plugin for the enemy truck (AICarController) and zombie train (AITrainController). Installed as BepInEx/plugins/TruckfulEnemyTuning.dll.

Close the game, edit BepInEx/config/local.truckful.enemytuning.cfg, then restart:

```ini
[Speed]
TruckMultiplier = 0.5
TrainMultiplier = 0.5

[Encounters]
TruckChanceMultiplier = 1
TrainChanceMultiplier = 1
```

Multipliers range from 0 to 1. Speed 0.5 means 50% of normal; 1 restores normal behavior. Chance 0.5 halves each spawner's original probability (80% becomes 40%); 0 suppresses chance-based encounters. Encounter chance is unchanged by default. Scripted Spawn/SpawnNow calls remain unchanged, so chance 0 does not guarantee removal of every boss encounter.

Truck patch scales EffectiveDesiredSpeedKMH, including the game's existing slower-boss multiplier. This changes its target speed, not a strict physical speed limit: charges, initial impulses and collisions can temporarily exceed it. Train patch scales UpdateForTime's time step only for its registered ChassisSplineFollowers; attack animation/tween timing remains unchanged. Existing amulet effects still apply. No save files or game binaries are modified.

From the repository root, build with `pwsh -NoProfile -File ./EnemyTuningMod/build.ps1`. Test with `pwsh -NoProfile -File ./EnemyTuningMod/test.ps1` in a fresh PowerShell 7 process. Tests use stand-ins and do not prove IL2CPP detouring or native gameplay behavior. Source dump method addresses differ from the installed binary; patches resolve named methods in the installed interop assemblies instead of hardcoding addresses.

In-game verification: check LogOutput.log for "Enemy tuning loaded", encounter both enemies, then try multipliers 1 and 0.5 on the same route. Check train wagons/attacks remain coherent. Chance changes need multiple visits to assess; test zero on a normal random spawn location. A game update can require rebuilding against regenerated interop libraries.

Disable: close the game and remove BepInEx/plugins/TruckfulEnemyTuning.dll. Keep the config if you want to retain settings.

## Installation

Requires **BepInEx 6.0.0-be.788+5b766a3, Unity IL2CPP, Windows x64**. Follow the [repository setup instructions](../README.md#requirements-and-installation) to install the loader and generate interop assemblies. Build requirements and an explicit `-GameRoot` example are in the [build guide](../README.md#build).

With the game closed, copy `TruckfulEnemyTuning.dll` from this folder into `<game>/BepInEx/plugins/`, then restart. The DLL is generated by `build.ps1`; it is not tracked in Git. To update, replace the installed DLL with the game closed. To uninstall, remove it.
