# Truckful Additional Objective

BepInEx 6 IL2CPP plugin. Makes the additional (medal) objective pass even if its requirements failed, for active and completed missions. Basic mission requirements still apply. Hidden and unstarted missions are not changed.

Installed DLL: `BepInEx/plugins/TruckfulAdditionalObjective.dll`. Restart the game to load it. BepInEx/LogOutput.log should contain `Additional objective patch loaded`.

The patch changes MissionLog.GoalIsMet only for the mission's MedalGoal, matching the native object address. This covers the journal, results, goal status, and medal achievement queries. It does not rewrite mission statistics or save files. Existing completed missions also receive the overridden evaluation while enabled. Medal-related achievements may persist after removing the mod.

Disable: close the game and remove the installed DLL. Original failed statistics remain, so the original evaluation returns after disabling.

Build from the repository root: `pwsh -NoProfile -File ./AdditionalObjectiveMod/build.ps1`.
Test from the repository root: `pwsh -NoProfile -File ./AdditionalObjectiveMod/test.ps1`. Tests compile the actual patch against stand-ins and check its decision logic; they do not verify native detouring.

In-game check: start/replay a mission with an additional objective, violate that requirement while preserving the basic goal, then finish the mission and check its result/journal medal. Basic mission failure should still work normally.

## Installation

Requires **BepInEx 6.0.0-be.788+5b766a3, Unity IL2CPP, Windows x64**. Follow the [repository setup instructions](../README.md#requirements-and-installation) to install the loader and generate interop assemblies. Build requirements and an explicit `-GameRoot` example are in the [build guide](../README.md#build).

With the game closed, copy `TruckfulAdditionalObjective.dll` from this folder into `<game>/BepInEx/plugins/`, then restart. The DLL is generated by `build.ps1`; it is not tracked in Git. To update, replace the installed DLL with the game closed. To uninstall, remove it.
